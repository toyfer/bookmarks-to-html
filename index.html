ブックマーク → インポート用HTML

Chrome / Edge / Firefox / Safari のブックマークを、どのブラウザでも読み込める Netscape 形式 HTML に変換します（ブラウザ内で完結・送信なし）

ブックマークファイルをここにドロップ

拡張子なしの Bookmarks、.jsonlz4、Bookmarks.plist、HTML、CSV/TSV、Markdown、URLリストに対応（複数可・自動判別）

Chrome / Edge は Bookmarks（拡張子なし）をそのまま選べます。Windows の場所: %LOCALAPPDATA%\Google\Chrome\User Data\Default\Bookmarks / %LOCALAPPDATA%\Microsoft\Edge\User Data\Default\Bookmarks

空フォルダを省く
追加日時を残す
ツリーを確認（最初の300件まで表示）
生成されたHTML（先頭のみ表示） 

  






  

    インポート手順とファイルの場所
    

      
ブラウザインポート元ファイルの場所

      
Chromeブックマークマネージャ（Ctrl+Shift+O）→ 右上「⋮」→ ブックマークをインポート%LOCALAPPDATA%\Google\Chrome\User Data\Default\Bookmarks

      
Edgeお気に入りの管理（Ctrl+Shift+O）→ 「…」→ お気に入りのインポート%LOCALAPPDATA%\Microsoft\Edge\User Data\Default\Bookmarks

      
Firefoxライブラリ（Ctrl+Shift+O）→ インポートとバックアップ → ブックマークを HTML からインポートbookmarks-YYYY-MM-DD.jsonlz4（バックアップ）

      
Safariファイル → ブックマークを読み込む~/Library/Safari/Bookmarks.plist

    

    
Chrome / Edge / Firefox は Netscape 形式 HTML を共通で読み込めます。ブックマークレット（javascript:）と内部URL（chrome: など）は、そのままでは他ブラウザで動かないため内部URLは自動的に除外します。

  






  すべての処理はブラウザ内で完結します（ファイルはアップロードされません）。出力は UTF-8・BOMなしの Netscape Bookmark File 形式です。
